# Fact-check: script v2 -> v3 (2026-11-05)

Method: every factual statement in script v2 was checked against the Vasa Museum (Vasamuseet, part of the Swedish
National Maritime and Transport Museums) and, where the museum makes a claim about itself, Visit Sweden. Direct page
fetches from vasamuseet.se were blocked in this session; claims were verified from the museum's own pages as returned
by web search (page titles, URLs and quoted passages). Re-open the links below before publishing.
